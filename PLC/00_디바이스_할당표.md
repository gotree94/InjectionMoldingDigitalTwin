# 미쓰비시 PLC 디바이스 할당표

- PLC: 미쓰비시 Q / iQ-R / iQ-F (FX5U 등)
- 프로그램: GX Works2 / GX Works3
- 레더 프로그램 내 디바이스 주소는 본 표와 동일하게 사용
- 리테인 권장: `L`, `D` (카운터, 래치 값 — 정전 시 복구)

---

## 1. 입력 디바이스 (X)

| 디바이스 | 신호명 | 설명 | 트윈 태그 |
|---------|--------|------|----------|
| X0 | INJ_COMPLETE | 사출 완료 신호 (사출기 → PLC) | inj_complete |
| X1 | EJECT_HOME | 이젝션 완료 (이젝터 상승 HOME) | eject_home |
| X2 | COUNT_SENSOR | 카운팅 센서 (컨베이어 진입부, 제품 감지) | count_sensor |
| X3 | VISION_OK | 비전 OK 결과 | vision_ok |
| X4 | VISION_NG | 비전 NG 결과 | vision_ng |
| X5 | VISION_DONE | 비전 검사 완료 스트로브 | vision_done |
| X6 | BIN_FULL | 불량 박스 풀 (리밋 센서) | bin_full |
| X7 | E_STOP | 비상정지 (NC: 안전 동작 시 OFF) | e_stop |
| X8 | GUARD_DOOR | 가드 도어 (NC) | guard_door |
| X9 | CONV_OCR | 컨베이어 모터 과부하 (OCR, NC) | conv_ocr |
| XA | MODE_SEL | 운전 절환 (ON=수동, OFF=자동) | mode_sel |
| XB | START_BTN | 스타트 버튼 | start_btn |
| XC | STOP_BTN | 스톱 버튼 | stop_btn |
| XD | RESET_BTN | 알람 리셋 버튼 | reset_btn |

## 2. 출력 디바이스 (Y)

| 디바이스 | 신호명 | 설명 | 트윈 태그 |
|---------|--------|------|----------|
| Y0 | CONV_MOTOR | 컨베이어 모터 구동 | conv_motor |
| Y1 | REJECT_BLOW | 리젝트 에어 블로우 (불량 배출) | reject_blow |

| Y3 | LAMP_RUN | 운전 표시 램프 | lamp_run |
| Y4 | LAMP_ALM | 이상(알람) 램프 | lamp_alm |
| Y5 | BUZZER | 부저 | buzzer |
| Y6 | EJECT_REQ | 이젝션 개시 지령 (이젝터 상승 지시) | eject_req |

| 디바이스 | 신호명 | 설명 | 트윈 태그 |
|---------|--------|------|----------|
| D0 | TOTAL_COUNT | 총 생산 카운트 (카운팅 센서 기준) | total_count |

| D10 | CYCLE_TIME | 사이클 타임 [0.1초] | cycle_time |

| D12 | CONV_SPEED | 컨베이어 속도 설정값 [%] | conv_speed |
| D13 | PITCH_MM | 제품 피치 [mm] (리젝트 동기화 보정용) | pitch_mm |
| D14 | REJECT_DELAY | 리젝트 지연 보정값 [10ms] | reject_delay |

| D20 | MOLD_TEMP | 금형 온도 [x0.1℃] | mold_temp |
| D21 | INJ_PRESSURE | 사출 압력 [x0.1 MPa] | inj_pressure |
| D22 | INJ_SPEED | 사출 속도 [x0.1 mm/s] | inj_speed |
| D23 | SHOT_COUNT | 샷 카운터 (금형 수명 관리) | shot_count |

| D101 | NG_TYPE1_COUNT | 결함 유형 1 (상처/스크래치) 카운트 | ng_type1 |
| D102 | NG_TYPE2_COUNT | 결함 유형 2 (이물/카본) 카운트 | ng_type2 |
| D103 | NG_TYPE3_COUNT | 결함 유형 3 (버어/플래시) 카운트 | ng_type3 |
| D104 | NG_TYPE4_COUNT | 결함 유형 4 (변형/위프) 카운트 | ng_type4 |
| D105 | NG_OTHER_COUNT | 기타 결함 카운트 | ng_other |
| D110 | SENSOR_STUCK_CNT | 카운팅 센서 스틱온 횟수 (진단) | sensor_stuck_cnt |
| D900 | ALARM_CODE | 현재 알람 코드 (0=정상) | alarm_code |

## 4. 비트 디바이스 (M) — 내부 릴레이

### 4.1 운전 상태 (래치 불필요)

| 디바이스 | 신호명 | 설명 |
|---------|--------|------|
| M0 | RUN_FLAG | 운전 중 플래그 |
| M1 | AUTO_MODE | 자동 모드 플래그 (안전 조건 만족 시) |
| M2 | ALARM_FLAG | 알람 상태 플래그 |
| M3 | SEQ_HOLD | 시퀀스 홀드 플래그 (인터록/불량박스 풀) |

### 4.2 시퀀스 스텝 (스텝 시프트)

| 디바이스 | 신호명 | 설명 |
|---------|--------|------|
| M10 | STEP_IDLE | 대기 상태 |
| M11 | STEP_EJECT | 이젝션 대기/실행 |

| M13 | STEP_VISION | 비전 검사 대기 |
| M14 | STEP_SORT_OK | 양품 분류 |
| M15 | STEP_SORT_NG | 불량 분류/리젝트 |

## 7. 비전 판정 코드 (D100)

| 코드 | 의미 | 분류 카운트 |
|------|------|-------------|
| 0 | OK (정상) | D1 증가 |
| 1 | 상처 / 스크래치 | D101 증가 |
| 2 | 이물 / 카본 | D102 증가 |
| 3 | 버어 / 플래시 | D103 증가 |
| 4 | 변형 / 위프 | D104 증가 |
| 5~9 | 기타 결함 | D105 증가 |
