# Unity 3D 씬 구성 가이드 — 사출 공장 디지털 트윈

> 이 문서는 `Unity/Scripts/*.cs`의 Inspector 필드와 씬의 3D 형상(형상·배치·재질)을 1:1로 맞추기 위한 가이드입니다.
> 좌표는 스크립트 기본값(`DigitalTwinController.cs`, `ProductSimulation.cs`) 기준으로 작성되었습니다.
> PLC 디바이스 매핑은 [`PLC/00_디바이스_할당표.md`](../PLC/00_디바이스_할당표.md)를 참조하세요.

---

## 1. 좌표계 설계 (컨베이어 = X축)

공정은 모두 **X축 한 방향(왼쪽→오른쪽)**으로 진행됩니다. 제품은 `z = 0` 라인 위를 이동합니다.

| 위치 | X 좌표 | 역할 | 연결 스크립트 필드 |
|------|--------|------|--------------------|
| 사출/이젝션 | `-2.0` | 금형 이젝션 → 제품 스폰 | `conveyorStartX` |
| 카운팅 센서 | `0.6` | 제품 카운트 (X2) | `sensorX` |
| 비전 검사 | `4.0` | 비전 스테이션 게이트 | `visionX` |
| 리젝터 | `6.5` | 불량 블로우 (Y1) | `rejectX` |
| 컨베이어 끝 | `9.0` | 양품 슈트 낙하 | `conveyorEndX` |
| 불량 박스 | `z = -1.0` | 불량 분기 목표 | `rejectZ()` (= -1.0 고정) |
| 제품 높이 | `y = 0.5` | 컨베이어 벨트 상면 | `startY` |

- 벨트는 대략 `x = -2.5 ~ 9.5` 범위(길이 약 12m)로 배치합니다.
- 제품은 `y = 0.5`, 크기 약 **0.1m 큐브**로 시작합니다. (스폰: `(conveyorStartX, 0.5, 0)`)

## 2. 권장 씬 계층 구조 (Hierarchy)

```
씬 이름: InjectionMoldingTwin
├── Directional Light                     # 전체 조명 (Soft Shadow 권장)
├── Main Camera                           # 사시각 배치 (아래 7 참조)
├── PLC Manager (빈 오브젝트)             # → PlcConnectionManager.cs
├── Twin Controller (빈 오브젝트)         # → DigitalTwinController.cs
├── Dashboard (빈 오브젝트)               # → TwinDashboard.cs
│
├── InjectionMachine                      # 사출기 본체 (금형 + 플래튼)
│   └── Mold                             # 이젝션 방향(X+) 쪽 끝
│       └── EjectorDummy                  # (선택) 이젝션 이동 연출용
│
├── Conveyor                              # 벨트 + 롤러 어셈블리
│   ├── Belt            (Plane 스트립)    # → ConveyorSimulation.beltMaterials
│   ├── Roller_Front   (Cylinder X축)     # → ConveyorSimulation.rollers
│   ├── Roller_Mid...  (Cylinder X축)
│   └── Roller_End     (Cylinder X축)
│
├── CountSensor                           # X = 0.6 (광센서 시각화 + 빔)
│   ├── SensorHousing  (Cube)
│   └── SensorBeam      (투명 Cube, 발광)
│
├── VisionStation                         # X = 4.0 (게이트 + 하이라이트)
│   ├── VisionFrame    (박스 프레임)      # → VisionInspection.frameRenderer
│   ├── CameraHead     (Cube, 카메라 렌즈)
│   └── HighlightLight (SpotLight)        # → VisionInspection.highlightLight
│
├── Rejecter                              # X = 6.5 (에어 노즐)
│   ├── Nozzle        (Cylinder)
│   └── AirFlowDummy  (선택, 블로우 연출)
│
├── RejectBox                             # z ≈ -1.0 부근 (불량 수거함)
├── GoodChute                             # X ≈ 9.0, 컨베이어 끝 아래 (슈트)
│
└── Products (빈 오브젝트)                # 생성 제품의 부모
                                            # → DigitalTwinController.productParent
```

> 씬에 스크립트 1개씩만 배치하는 것이 전제입니다. `GetConveyor()`, `GetVision()`이
> `FindObjectOfType<T>()`로 자동 검색하므로 **ConveyorSimulation / VisionInspection은 각 1개**만 두세요.

## 3. 오브젝트별 구성 상세

### 3.1 InjectionMachine (사출기)
- 금형 캐비티 출구가 `x = -2.0 ~ -1.5` 구간에 오도록 배치.
- 이젝션 완료(X1) 연출은 이젝터 실린더가 X+로 밀리는 이동 애니메이션으로 구성하면 자연스럽습니다.
- `DigitalTwinController`의 `ejectTimeSec` 기본값 `1.0`초 동안 위 연출을 반영하면 됩니다.

### 3.2 Conveyor (컨베이어)
- **Belt**: Plane 또는 길쭉한 Cube. 길이 약 12m(스케일 `(1, 1, 12)`), 위치 `(3.5, 0, 0)`.
  - 표면이 위로 오도록 보통 `X 90°` 회전. `Renderer.material`이 벨트 재질.
  - 벨트 재질은 **Main Texture(Repeat Wrap 모드)** 사용 → `mainTextureOffset` 스크롤로 움직임 표현.
  - `beltMaterials[]`에 이 재질을 넣으면 스크립트가 자동 스크롤합니다.
- **Rollers**: 원통을 X축으로 눕혀 놓고 `rollers[]`에 Transform을 채우면 연출용 회전.
- `scrollPerMeter` 기본 `0.5` → 벨트 텍스처가 너무 빠르거나 느리면 조정.

### 3.3 CountSensor (카운팅 센서)
- `x = 0.6` 위치. 제품 직경 만큼 빔 높이(`y ≈ 0.5`)로 투명 Cube 배치.
- 스크립트상 센서 ON/OFF는 `CountSensor`(X2) 값으로 표현(시뮬레이션 시 자동).

### 3.4 VisionStation (비전 검사)
- 게이트 프레임(`VisionFrame`) 중심이 `x = 4.0`.
- `SpotLight`(`HighlightLight`)가 게이트 안쪽을 비추도록 위치·각도 설정.
- `VisionInspection` Inspector:
  - `highlightLight` ← HighlightLight (SpotLight)
  - `frameRenderer`  ← VisionFrame의 Renderer
  - `okMaterial`     ← 초록(양품) 재질
  - `ngMaterial`     ← 빨강(불량) 재질
  - `idleMaterial`   ← 대기(회색) 재질
  - `label`          ← (선택) TMP 텍스트 (Python 없이 순수 UnityEngine 사용)

### 3.5 Rejecter (리젝터)
- 노즐 중심 `x = 6.5`, `z = 0` 부근에서 컨베이어 쪽(-z → 불량 박스 방향)으로 분사 방향 설정.
- `RejectBlow`(Y1) ON 시 에어 블로우 연출(Source 시스템 등)을 트리거하면 됩니다.

### 3.6 RejectBox (불량 박스)
- 중심 `(약 6.4, 0, -1.0)`. `ProductSimulation.rejectDropDepth`(기본 `0.9`)만큼 낙하.
- 위가 열린 상자 형태(4면 Cube 조립) 권장.

### 3.7 GoodChute (양품 슈트)
- `x = 9.0` 아래(컨베이어 끝)에 경사 슈트 배치. 제품이 `goodDropDepth`(기본 `0.9`) 만큼 낙하 후 수거.

### 3.8 Products (생성물 부모) + Product 프리팹
1. `Assets/Prefabs/Product.prefab` 생성:
   - 루트 Transform + `ProductSimulation.cs` 부착.
   - 자식 또는 루트에 큐브(약 `0.1m`) → `childCount > 0`이므로 스폰 시 위치 자동 설정.
   - 4개 결함 색상용 재질 옵션(하단 5절).
2. 씬의 `Products` 빈 오브젝트를 `DigitalTwinController.productParent`에 지정(선택, 미지정 시 Controller 하위).

## 4. 스크립트 연결 (Inspector 배선 요약)

### 4.1 DigitalTwinController (Twin Controller에 부착)
| Inspector 필드 | 값 |
|----------------|-----|
| `mode` | `Simulation` 또는 `Live` |
| `plcManager` | Live 모드에서 `PLC Manager` 오브젝트의 `PlcConnectionManager` 참조 |
| `conveyorStartX / sensorX / visionX / rejectX / conveyorEndX` | 기본값 유지(`-2.0/0.6/4.0/6.5/9.0`) |
| `rejectDuration` | `0.5` (불량 블로우 지속 시간) |
| `cycleTimeSec` | `12.0` (사출 사이클) |
| `ejectTimeSec` | `1.0` (이젝션 시간) |
| `beltSpeed` | `1.0` (제품 이동 속도 m/s) |
| `defectRate` | `0.08` (불량률 8%) |
| `productPrefab` | `Product.prefab` 참조 |
| `productParent` | `Products` 오브젝트 |

### 4.2 PlcConnectionManager (PLC Manager에 부착)
| Inspector 필드 | 값 |
|----------------|-----|
| `plcIp` | PLC IP (예: `192.168.3.39`) |
| `plcPort` | `5001` |
| `timeoutMs` | `2000` |
| `pollingIntervalMs` | `25` |

### 4.3 ConveyorSimulation (Belt 오브젝트에 부착)
| Inspector 필드 | 값 |
|----------------|-----|
| `beltMaterials` | 벨트 재질 배열 (1개 이상) |
| `scrollPerMeter` | `0.5` |
| `rollers` | Roller Transform 배열 |

### 4.4 VisionInspection (VisionStation에 부착) / ProductSimulation (Product 프리팹)
- 각각 3.4절, 3.8절의 Inspector 값 사용.
- `ProductSimulation` 필드(`startY`, `rejectDropDepth`, `goodDropDepth`, `divergeSpeed`, `dropSpeed`)는 기본값 유지 권장.

### 4.5 TwinDashboard (Dashboard에 부착)
| Inspector 필드 | 값 |
|----------------|-----|
| `twinController` | `Twin Controller`의 `DigitalTwinController` |
| `left / top / scale` | 화면 위치·크기 (기본 `16 / 16 / 1.25`) |

## 5. 머티리얼 구성

| 용도 | 셰이더/설정 | 색/텍스처 |
|------|-------------|-----------|
| 벨트 (`beltMaterials`) | URP/Standard, Main Texture **Wrap = Repeat** | 그레이 고무 텍스처 (화살표 패턴 권장) |
| 비전 대기 `idleMaterial` | Standard | 회색 |
| 비전 양품 `okMaterial` | Standard (Emissive) | 초록 |
| 비전 불량 `ngMaterial` | Standard (Emissive) | 빨강 |
| 제품 기본 | Standard | 흰색/연회색 폴리머 |
| 불량 제품 (선택) | Standard | 결함에 따라 적갈색/노란색으로 교체 연출 |

> 벨트 재질은 `ConveyorSimulation`이 `mainTextureOffset`을 제어하므로,
> 텍스처 Import Settings에서 **Wrap Mode = Repeat, Aniso Level**을 켜 두세요.

## 7. 카메라 배치 참고

- 메인 카메라는 **측면 사시각** 권장: 가령 `Position (4.5, 7.0, -8.0)`, `Rotation (arccos 시), 45°, 0` 수준.
- 미니맵/리젝터 줌은 별도 카메라로 추가해도 좋습니다.
- `TwinDashboard`는 OnGUI이므로 Game View 해상도 변화에 따라 `scale` 값을 조정하면 됩니다.
