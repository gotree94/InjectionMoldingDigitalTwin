## 1. 프로젝트 개요

사출 성형(Injection Molding) 공장의 **사출 → 이젝션 → 카운팅 → 비전 검사 → 양품/불량 분류** 공정을
미쓰비시 PLC(Q/R/iQ-F 시리즈)로 제어하고, 동일 공정을 **Unity 3D 디지털 트윈**으로 실시간 동기화하는
프로젝트입니다.

- **제어**: 미쓰비시 PLC 레더 프로그램 (GX Works2/3 호환)
- **시각화・시뮬레이션**: Unity (C#)
- **통신**: MC Protocol 3E 프레임 (Ethernet TCP/IP, 기본 포트 5001)

공장 레이아웃 구성:

```
┌─────────────┐      ┌──────────────┐      ┌───────────────┐      ┌─────────────────┐
│   사출기     │ ──▶  │  카운팅 센서   │ ──▶  │  비전 검사실   │ ──▶  │   분류 리젝터    │
│ Injection   │ 이젝  │  (개수 카운트) │      │  (정상/불량)   │      │ (양품▶ 정상로)   │
│ Molding     │      └──────────────┘      └───────────────┘      │  (불량▶ 불량박스) │
│ (금형)      │                                                 └─────────────────┘
└─────────────┘
```

## 2. 공정 시나리오 (보강 반영)

### 2.1 기본 흐름

| 번호 | 공정 | 설명 |
|------|------|------|
| 1 | **사출** | 금형에 수지 주입 → 냉각 → 형개 → 이젝터 상승 |
| 2 | **이젝션** | 이젝터가 제품을 금형에서 밀어내어 컨베이어로 낙하 적재 |
| 3 | **카운팅** | 컨베이어 진입부 카운팅 센서가 생산 제품 개수 집계 |
| 4 | **비전 검사** | 비전 카메라로 정상/불량 판정 (결함 유형 분류 포함) |
| 5 | **분류** | 정상 → 정상 컨베이어 계속 이송, 불량 → 리젝터(에어 블로우)로 불량 박스 배출 |
| 6 | **집계** | 총 생산, 양품, 불량 개수 집계 및 KPI 계산 |

### 2.2 보강 포인트 (실제 공장 반영)

초기 시나리오에 아래 내용을 보강했습니다.

#### A. 사출기 상태 모니터링
| 항목 | 설명 |
|------|------|
| 사출 압력 | 금형 충진 압력 모니터링 → 불량 예측 지표 |
| 실린더/금형 온도 | 수지 온도 구배 이상 감지 |
| 사이클 타임 | 사출 사이클 실제 시간 측정 (OEE 지표) |
| 샷 카운터 | 금형 수명 관리 (금형 교체 주기 산출) |

#### B. 이젝션 타이밍 동기화
- 이젝터 **상승(HOME) 완료 신호** 후 제품 적재 신호 발생
- 컨베이어 진입부에서 제품 도착 확인 → 카운팅 시작

#### C. 카운팅 로직 보강
- 접점 채터링 제거용 **필터 타이머** (예: 20ms)
- 제품 간 피치(pitch) 정합 검증으로 **이중 카운팅 방지**
- 센서 이상 감지 (스틱온/스틱오프) → 알람

#### D. 비전 검사 – PLC 연동 보강
- 비전 결과는 `OK / NG` + **결함 유형 코드**로 PLC에 전달
- PLC는 결과를 **래치(Keep)** 한 뒤, 제품이 리젝터 위치에 도달하는
  **지연 시간(피치 × 속도 보상)** 을 계산하여 리젝트 신호 발생
- 제품 간 거리 불일치 시 미스 리젝트 감지

#### E. 분류 동기화
- 리젝터(에어 블로우) 작동은 비전 판정 시점이 아니라 **제품 도달 시점** 기준
- 리젝터 솔레노이드 듀티(작동 시간) 파라미터화

#### F. 안전 인터록
- 비상정지(E-Stop), 가드 도어, 컨베이어 모터 과부하(OCR)
- 인터록 조건 불만족 시 시퀀스 홀드 + 알람 표시

#### G. 정전/재기동 복구
- 카운터, 래치값을 **리테인 디바이스(L, D 디바이스)** 로 관리
- 재기동 시 운전 상태 자동 복구 (사출 중간 재개 시나리오 정의)

#### H. 디지털 트윈 모드 분리
| 모드 | 설명 |
|------|------|
| **시뮬레이션 모드** | PLC 없이 Unity 내 로직만으로 동작 (개발/시연용) |
| **라이브 모드** | 실제 PLC와 MC Protocol 3E로 실시간 동기화 |

#### I. KPI 대시보드
| 지표 | 계산 |
|------|------|
| 총 생산 개수 | 카운팅 센서 누적 |
| 양품 개수 | 비전 OK 누적 + 카운트 정합 검증 |
| 불량 개수 | 비전 NG 누적 |
| 불량률 | 불량 / 총 생산 × 100 |
| 결함 유형별 분포 | 상처/이물/버어/변형 등 유형별 카운트 |
| 사이클 타임 추이 | 이동 평균 + 최신값 표시 |
| OEE | 가동률 × 성능률 × 품질률 |

## 3. 시스템 아키텍처

```
┌─────────────────────────────────────────────────────────────┐
│                        Unity (Digital Twin)                 │
│  ┌─────────────────┐   ┌──────────────────────────────────┐  │
│  │  Twin Controller │   │  Conveyor / Vision / Product      │  │
│  │  (MonoBehaviour) │   │  Simulation (시뮬레이션 모드)      │  │
│  └────────┬────────┘   └──────────────────────────────────┘  │
│           │                                                   │
│  ┌────────▼─────────┐                                        │
│  │  McProtocolClient │  ← MC Protocol 3E, TCP:5001            │
│  │  + PlcDeviceMap   │                                        │
│  └────────┬─────────┘                                        │
└───────────┼───────────────────────────────────────────────────┘
            │ Ethernet TCP/IP
┌───────────▼───────────────────────────────────────────────────┐
│                 Mitsubishi PLC (Q / R / iQ-F, FX5U)           │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 메인 시퀀스 │ 카운팅 │ 비전 연동 │ 분류 리젝트 │ 안전 인터록 │  │
│  └──────────────────────────────────────────────────────────┘  │
│        ▲                 ▲                  ▲                   │
│   X0~ 사출기/센서   비전 OK/NG 신호   Y0~ 컨베이어/블로우        │
└────────────────────────────────────────────────────────────────┘
```

### 3.1 PLC ↔ 비전 시스템 연동

비전 검사기는 PLC의 이더넷 모듈 또는 직접 I/O로 연결합니다.

| 경로 | 설명 |
|------|------|
| **직접 I/O 방식** | 비전에서 `OK(Y-pulse) / NG 신호`를 PLC 입력(X)으로 수신 |
| **이더넷(TCP/IP) 방식** | 비전 판정 코드를 PLC 태그/레지스터(D)에 기록 |

본 프로젝트는 결함 유형까지 수집하기 위해 **D 레지스터 기반 판정코드 전송**을 권장합니다.

### 3.2 디바이스 통신 규약

- **프로토콜**: MC Protocol 3E 프레임 (바이너리), Ethernet TCP
- **포트**: 5001 (PLC 내 MC 프로토콜 활성화 필요 — GX Works에서 설정)
- **폴링 주기**: 40~50 Hz (20~25ms) 권장 — 실시간 반영과 네트워크 부하 균형

## 4. PLC 디바이스 할당표 (요약)

상세한 전체 표는 [`PLC/00_디바이스_할당표.md`](PLC/00_디바이스_할당표.md) 참조.

| 구분 | 디바이스 | 내용 |
|------|---------|------|
| 입력 | `X0` | 사출 완료 신호 (사출기 → PLC) |
| 입력 | `X1` | 이젝션 완료 (이젝터 상승HOME) |
| 입력 | `X2` | 카운팅 센서 (컨베이어 진입부) |
| 입력 | `X3` | 비전 OK 신호 |
| 입력 | `X4` | 비전 NG 신호 |
| 입력 | `X5` | 비전 검사 완료 신호 |
| 입력 | `X6` | 불량 박스 풀 (리밋 센서) |
| 입력 | `X7` | 비상정지 (E-Stop) |
| 입력 | `X8` | 가드 도어 |
| 입력 | `X9` | 컨베이어 모터 과부하 (OCR) |
| 입력 | `XA` | 운전 절환 (자동/수동) |
| 입력 | `XB` | 스타트 버튼 |
| 입력 | `XC` | 스톱 버튼 |
| 입력 | `XD` | 리셋 버튼 |
| 출력 | `Y0` | 컨베이어 모터 |
| 출력 | `Y1` | 리젝트 에어 블로우 (불량 배출) |
| 출력 | `Y2` | 사출기 기동 지령 (출력으로 시퀀스 시작) |
| 출력 | `Y3` | 운전 표시 램프 |
| 출력 | `Y4` | 이상(알람) 램프 |
| 출력 | `Y5` | 부저 |
| 출력 | `Y6` | 이젝션 개시 지령 |
| 데이터 | `D0` | 총 생산 카운트 |
| 데이터 | `D1` | 양품 카운트 |
| 데이터 | `D2` | 불량 카운트 |
| 데이터 | `D10` | 사이클 타임 (0.1초 단위) |
| 데이터 | `D11` | 목표 생산량(SET VALUE) |
| 데이터 | `D20` | 컨베이어 속도 설정값 |
| 데이터 | `D30` | 금형 온도 |
| 데이터 | `D31` | 사출 압력 |
| 데이터 | `D32` | 사출 속도 |
| 데이터 | `D33` | 샷 카운터 (금형 수명) |
| 데이터 | `D100` | 비전 판정 코드 (0:OK, 1~N:결함 유형) |
| 데이터 | `D101~` | 결함 유형별 카운트 |

## 6. 설치 및 실행

### 6.1 Unity 프로젝트 설정
1. Unity Hub에서 **2022.3 LTS** 프로젝트 생성
2. `Assets/Scripts` 아래에 `Unity/Scripts/*.cs` 복사
3. 씬 구성
   - 빈 GameObject `PLC Manager` → `PlcConnectionManager.cs` 부착
   - 빈 GameObject `Twin Controller` → `DigitalTwinController.cs` 부착
   - `Conveyor` (스트립으로 구성) → `ConveyorSimulation.cs` 부착
   - `Vision Station` → `VisionInspection.cs` 부착
   - 제품 프리팹 `Product` → `ProductSimulation.cs` 부착
4. 인스펙터에서 PLC IP / 포트 / 폴링 주기 설정

### 6.2 PLC 설정 (GX Works)
1. 이더넷 파라미터 > MC 프로토콜 활성화 (포트 5001)
2. 통신 데이터 코드: **바이너리(Binary)** 
3. Read/Write 권한 설정
4. 레더 프로그램은 `PLC/*.txt` 파일 내용을 GX Works2/3에 입력
   - 디바이스명과 주소는 `00_디바이스_할당표.md`와 동일하게 유지

### 6.3 모드 운용
| 모드 | 설정 |
|------|------|
| 시뮬레이션 | `DigitalTwinController`의 `UseSimulation` = `true` (PLC 미연결) |
| 라이브 | `UseSimulation` = `false`, PLC IP 입력 |

## 8. 시퀀스 타임라인 (사이클)

```
[사출기]  사출 시작 ──▶ 사출 완료(X0)
[금형]    냉각/형개 ──▶ 이젝션 개시(Y6)
[이젝터]  상승 ──▶ 이젝션 완료(X1)
[컨베이어] 제품 적재 → 카운팅 센서(X2) ON/OFF → 카운트 증가(D0)
[비전]     스테이션 도달 → 검사 → 판정코드(D100) + OK/NG(X3/X4)
[분류]     양품 → 정상 로 이송 / 물량 → 리젝트 에어 블로우(Y1) → 불량박스
[집계]     D0/D1/D2 갱신 → KPI 계산
```
